# SAMURAI Core Integration

Integration layer for SAMURAI / X10THINC over HAMYLION Core 3.0.

## Flow

Android/client -> SAMURAI Core -> HAMYLION /v1/events -> PostgreSQL -> Redis Stream -> worker -> WebSocket.

This layer does not perform hidden device control. Device actions must remain explicitly authorized by the Android permission/consent layer.

## Event contract

Every event has:
- `id` generated by HAMYLION
- `type`
- `payload`
- `idempotency_key`
- optional `module`, `source`, `schema_version`

## Modules

The software module registry is compatible with the existing 12-module SAMURAI design:
1. screen_vision
2. ui_analyzer
3. user_intent
4. device_optimizer
5. security_guardian
6. macro_executor
7. audio_perception
8. network_awareness
9. cloud_sync
10. self_improvement
11. visual_persona
12. private_core

These are software modules, not twelve trained ML models.
