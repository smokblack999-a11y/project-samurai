# X10THINK MoneyProof Engine

The engine ranks opportunities by evidence, not model enthusiasm.

## Decision gate

- `A PAID` or `B BUYING_INTENT` -> `BUILD`
- `C QUALIFIED_DEMO` or `D BUDGET_PAIN` -> `SELL_TEST`
- `E WEAK` -> `RESEARCH`
- `F SPECULATION` -> `KILL`

## Core loop

`SIGNAL -> OPPORTUNITY -> ASSUMPTION -> EVIDENCE -> KILL -> MONEY PROOF -> DECISION`

An opportunity without evidence is unverified. A high score never overrides missing commercial proof.

## Safety

Dynamic verification must run only against authorized, local, or intentionally vulnerable targets. The engine is for defensive validation and commercial decision-making, not unauthorized exploitation.
