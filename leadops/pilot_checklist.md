# First Paid Pilot

- [ ] Obtain explicit client permission for message processing.
- [ ] Export only the minimum required messages.
- [ ] Redact phone numbers, emails and usernames.
- [ ] Label 100 messages with human-reviewed intent/action/outcome.
- [ ] Run baseline benchmark.
- [ ] Run AI benchmark with existing server-side API key.
- [ ] Compare precision, recall and F1.
- [ ] Measure latency and API spend.
- [ ] Calculate client ROI using observed outcomes.
- [ ] Review false positives with the client.
- [ ] Run 7-day pilot with human approval for every outbound action.
- [ ] Ask for payment only after measurable value is demonstrated.
