# Pilot Scorecard

## Technical
- 100 real labeled messages
- precision >= 0.90
- recall >= 0.85
- F1 >= 0.87
- no duplicate event processing
- no autonomous outbound messaging

## Commercial
- 10 qualified prospects contacted
- 5 demos
- 3 pilots
- 1 paid pilot
- customer can explain the value in 30 seconds
- measurable change in response prioritization or qualified-lead capture

## Kill rule
If the commercial funnel fails, stop adding features and change the offer or ICP.
