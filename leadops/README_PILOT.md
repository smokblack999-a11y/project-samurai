# Pilot execution

1. Obtain explicit customer authorization.
2. Export 100 representative messages.
3. De-identify the evaluation copy.
4. Human-label intent and action.
5. Run baseline benchmark.
6. Run AI benchmark with the existing runtime key.
7. Compare precision, recall, F1 and latency.
8. Calculate actual AI cost.
9. Review false positives with the customer.
10. Produce the ROI report only from measured customer data.
