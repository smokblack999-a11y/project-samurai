# LeadOps operating gates

1. API key is reused securely and never committed.
2. Health endpoint passes.
3. Deterministic baseline passes.
4. AI benchmark runs when a key is configured.
5. Telegram updates normalize correctly.
6. Duplicate events are idempotent.
7. SQLite persistence succeeds.
8. Message text is absent from ordinary logs.
9. Outbound messaging remains disabled.
10. 100 real messages are labeled.
11. Precision, recall and F1 are measured.
12. Cost per message is measured.
13. Customer ROI is estimated from observed data.
14. One paid pilot is obtained.
15. Only then consider production outbound automation.

Kill rule: if 10 qualified prospects produce no serious pilot interest, stop feature expansion and change the offer or ICP.
